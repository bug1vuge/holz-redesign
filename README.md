# HOLZ — концепт редизайна сайта holzdoors.ru

Демо-версия нового сайта производителя дверей HOLZ Interior Doors: главная страница со сценами, которые разворачиваются при прокрутке, и все основные внутренние разделы. Данные статичные, для презентации.

**Демо:** https://bug1vuge.github.io/holz-redesign/

## Стек
React 18 · TypeScript · Vite · GSAP + ScrollTrigger + Flip · Lenis (плавный скролл) · React Router

## Страницы
- `/` — главная: 9 анимированных сцен (дверь-портал, анатомия двери, смена покрытий, лента коллекций, скрытая дверь Illusion, высота до 3000 мм, каталог, карта салонов, расчёт)
- `/katalog`, `/katalog/:раздел`, `/katalog/:раздел/:модель` — каталог с фильтрами и конфигуратором двери
- `/gde-kupit`, `/akcii`, `/press`, `/dizajneram`, `/o-kompanii` (+ технологии, сертификаты, отзывы, контакты)

## Запуск
```bash
npm install
npm run dev
```
Изображения дверей рисуются в SVG и перекрашиваются под выбранное покрытие; в рабочей версии их можно заменить фото и 3D-рендерами.
